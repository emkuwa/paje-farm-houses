PAJE FARM HOUSES — LOCAL PROJECT

1. Extract this ZIP.
2. Open index.html in your browser.
3. For full local browser functionality, open a terminal in this folder and run:
   python3 -m http.server 8000
   On Windows you may use: py -m http.server 8000
4. Visit http://localhost:8000

Edit index.html in VS Code or another editor. Images are in assets/.
No npm install or build is required.

The enquiry form prepares copyable messages; it does not send bookings.
My Plant is a demo. No database, payments or live plant records are connected.
Fonts load from Google Fonts; remaining stock imagery may need internet access.
The four generated images are included locally.

Published project: https://www.pajefarmhouses.com
(Older ChatGPT-hosted preview URL is login-gated and no longer public.)
